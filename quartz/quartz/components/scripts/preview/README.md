# 普通文件预览

普通文件预览与 Jellyfin 播放独立；此处不改变播放协商策略。

| 文件 | 职责 |
| --- | --- |
| `../drivePreview.ts` | 页面权限、预览选择、隔离 frame 生命周期及消息桥接 |
| `../drivePreviewSandbox.ts` | frame 内环境、资源读取和多格式预览分发 |
| `sandboxTypes.ts` | 共用的预览配置类型，不包含运行状态 |
| `videoRenderer.ts` | 普通视频播放器、容器格式、字幕、音量及换源状态 |
| `../jellyfin/` | Jellyfin 受控播放器与独立播放控制器 |

普通预览在隔离 iframe 内执行。运行函数经 `toString()` 序列化，不能隐式捕获模块变量；跨模块依赖由启动函数显式传入。扩展渲染器后要验证生产压缩后的函数仍能独立执行。

保持现有资源来源、样式、加载顺序和父子窗口协议。页面离开时释放 frame 和媒体；资源缓存与普通查询缓存分工见 [缓存约定](../../../../../architecture/cache.md)。
