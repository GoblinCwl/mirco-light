# 媒体播放验证

本文是验证清单，不是当前版本已经通过的浏览器验证报告。未经维护者明确要求，不执行浏览器测试。

自动检查覆盖播放协商、权限、播放状态、字幕、HLS 时间轴、续播、取消和故障回退。测试入口分别位于 `quartz/components/scripts/jellyfin/` 和同级 `quartz-server/internal/jellyfin/`。

维护者手动验证重点：

- 无字幕、SubRip、WebVTT、ASS/SSA、PGS 的首播和续播。
- 自动、原画与固定画质；音轨、字幕切换后保持位置和播放意图。
- 播放中和暂停时拖动、切换失败后的回滚、离页后的资源释放。
- 普通文件预览的文本、图片、音频、普通视频、文档与压缩包。
- 桌面和移动端的全屏、音量、明暗主题及选集。

结果必须记录实际设备、浏览器、片源类型和操作结果，不能将构建成功或历史测试结果当作当前浏览器验证结论。调用链和模块边界见 [播放器说明](README.md)。
